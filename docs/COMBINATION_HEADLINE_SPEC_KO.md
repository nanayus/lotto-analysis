# 조합 분석 대표 설명 문구 명세

문서 버전: 1.0  
작성 기준일: 2026-09-06

## 1. 목적

조합 분석 결과 상단에서 과거 데이터 중 먼저 읽을 가치가 있는 특징을 결정론적으로 설명한다. 대표 설명은 조합의 품질, 당첨 가능성 또는 미래 출현을 평가하지 않는다.

AI 조합 해설과는 별개다. 대표 설명은 `CombinationAnalysis`만 입력받는 순수 도메인 함수에서 생성한다.

## 2. 표시 구조

```text
번호 히어로
분석 조건

주요 분석
● 대표 특징 한 문장
  대표 근거
────────────────
● 필요한 경우 다른 지표군의 보조 특징 한 문장
  보조 근거
```

- 선택 번호는 둥근 카드가 아닌 결과 화면 상단의 흰색 히어로 영역으로 표시한다.
- 주요 분석은 분석 조건 아래에 배치해 조건 변경과 결과 변화의 관계를 보여준다.
- 주요 분석 자체에는 별도 카드, 테두리 또는 알약형 배지를 사용하지 않는다.
- 대표 문장은 한 개만 표시한다.
- 보조 문장은 대표 문장과 다른 지표군에서 최대 한 개만 표시한다.
- 동일 입력과 동일 필터에는 항상 같은 문구가 나온다.
- 각 특징은 작은 상태점, 설명 문장, 작은 근거 문구 순서로 표시한다.
- 평균 출현 간격의 2배 이상 미출현한 번호의 상태점과 근거만 `hot` 토큰을 사용한다.
- 다른 상태점은 활성 테마의 `accentPrimary`, 설명과 근거는 기본 텍스트 토큰을 사용한다.

## 4. 과거 당첨번호와 하위 조합

| 경우 | 문구 | 근거 |
|---|---|---|
| 동일 6번호 1회 | `{회차}회 1등 본번호와 정확히 같은 조합이에요.` | `본번호 6개 일치` |
| 동일 6번호 여러 회 | `과거 {횟수}개 회차의 1등 본번호와 같아요. 가장 최근은 {회차}회예요.` | `동일 6번호 · {횟수}회` |
| 본번호 5개와 보너스 일치 | `{회차}회 당첨번호와 본번호 5개, 보너스 번호가 일치해요.` | `2등 기록 · {회차}회` |
| 본번호 5개 일치 | `{회차}회 당첨번호와 본번호 5개가 일치해요.` | `3등 기록 · {회차}회` |
| 본번호 5개 기록 여러 회 | `본번호 5개가 일치한 기록이 {횟수}회 있어요. 가장 최근은 {회차}회예요.` | `5번호 일치 · {횟수}회` |
| 기간 대비 두드러진 4번호 | `{번호 4개} 네 번호가 선택 기간에 {횟수}번 함께 나왔어요.` | `4번호 조합 · {횟수}회` |
| 번호쌍 집중 | `선택한 번호쌍 중 가장 자주 함께 나온 것은 {번호쌍}예요.` | `{번호쌍} {횟수}회 · 선택 쌍 평균 {평균}회` |
| 번호쌍 공동 1위 | `가장 자주 함께 나온 번호쌍은 {번호쌍 A}와 {번호쌍 B}로, 각각 {횟수}회예요.` | 같은 기준 |

4번호는 전체 범위에서 단순 1회 출현만으로 대표 후보가 되지 않는다. 104회 이하 범위에서는 1회, 그보다 긴 범위에서는 2회 이상이어야 후보가 된다. 번호쌍은 선택한 같은 크기 조합의 평균보다 1.35배 이상일 때 후보가 된다.

3번호 조합의 반복 횟수나 반복된 조합 개수는 가능한 조합 수가 많고 긴 분석 기간에는 반복이 흔해 의미를 직관적으로 전달하기 어렵다. 따라서 `주요 분석` 후보로 사용하지 않으며, 실제 번호와 출현 횟수는 `자주 나온 조합` 상세 영역에서만 제공한다.

## 5. 그룹 및 개별 번호 출현

| 경우 | 문구 | 근거 |
|---|---|---|
| 선택 평균이 전체보다 높음 | `선택한 번호들은 전체 번호보다 평균 {차이}% 더 자주 나왔어요.` | `선택 평균 {A}회 · 전체 평균 {B}회` |
| 선택 평균이 전체보다 낮음 | `선택한 번호들은 전체 번호보다 평균 {차이}% 적게 나왔어요.` | 같은 기준 |
| 선택 번호 중 한 번호가 높음 | `선택 번호 중 {번호}번의 과거 출현 횟수가 가장 많아요.` | `{번호}번 {횟수}회 · 전체 {순위}위` |
| 선택 번호 중 한 번호가 낮음 | `선택 번호 중 {번호}번의 과거 출현 횟수가 가장 적어요.` | 같은 기준 |

- 그룹 평균은 표본 10회 이상, 전체 평균 대비 절대 차이 5% 이상에서 사용한다.
- 개별 번호는 전체 평균 대비 차이 8% 이상일 때 사용한다.
- 표본 10회 미만에서는 빈도 차이를 강한 특징으로 설명하지 않는다.

## 6. 평균 출현 간격

| 경우 | 문구 | 색상 |
|---|---|---|
| 현재 미출현이 평균 이하 | 대표 후보 제외 | 기본 |
| 평균 초과, 2배 미만 | `{번호}번은 평균 출현 간격 {평균}회보다 긴 {현재}회째 미출현이에요.` | accent |
| 평균의 2배 이상 | `{번호}번은 평균 출현 간격의 {배수}배인 {현재}회째 미출현이에요.` | hot |
| 선택 기간 내 출현 기록 없음 | `{번호}번은 선택한 {회차 수}회 동안 출현 기록이 없어요.` | accent |
| 평균 계산 불가 | 평균 비교 문구를 만들지 않음 | 기본 |

출현 횟수가 2회 미만이거나 평균 출현 간격이 0이면 후보에서 제외한다. 미출현이 길다는 사실을 미래 출현 신호처럼 표현하지 않는다.

## 7. 연속·홀짝·저고

| 경우 | 문구 |
|---|---|
| 연속 2개 | `{번호 2개}, 두 번호가 연속으로 이어져 있어요.` |
| 연속 그룹 여러 개 | `연속 번호 그룹이 {개수}개 있어요: {그룹 목록}.` |
| 연속 3개 | `{번호 3개}, 세 번호가 연속으로 이어져 있어요.` |
| 연속 4–6개 | `{시작}부터 {끝}까지 {개수} 번호가 연속으로 이어져 있어요.` |
| 홀짝 6:0 또는 0:6 | `여섯 번호가 모두 {홀수/짝수}예요.` |
| 홀짝 5:1 또는 1:5 | `{홀수/짝수}가 5개로 구성의 대부분을 차지해요.` |
| 홀짝 4:2 또는 2:4 | `홀수가 {홀수 수}개, 짝수가 {짝수 수}개예요.` |
| 홀짝 3:3 | `홀수와 짝수가 3개씩 나뉘어 있어요.` |
| 저고 6:0 또는 0:6 | `여섯 번호가 모두 {22 이하의 저수/23 이상의 고수}예요.` |
| 저고 5:1 또는 1:5 | `{저수/고수}가 5개로 구성의 대부분을 차지해요.` |
| 저고 4:2 또는 2:4 | `저수가 {저수 수}개, 고수가 {고수 수}개예요.` |
| 저고 3:3 | `저수와 고수가 3개씩 나뉘어 있어요.` |

2개 연속, 홀짝 4:2·3:3, 저고 4:2·3:3은 주로 보조 문장으로 사용한다.

## 8. 합계·분산·A/C

활성 기간의 실제 당첨 본번호 6개를 비교 집단으로 사용해 백분위 위치를 계산한다. 52회 미만 표본에서는 이 분류를 대표 후보로 사용하지 않는다.

| 경우 | 문구 | 근거 |
|---|---|---|
| 합계 하위 10% | `번호 합계는 {합계}이며 과거 당첨 조합 중 낮은 쪽 10% 구간에 있어요.` | `합계 {합계} · 하위 10% 구간` |
| 합계 하위 25% | `번호 합계는 {합계}이며 과거 기록에서 비교적 낮은 구간에 있어요.` | `합계 {합계} · 하위 25% 구간` |
| 합계 상위 25% | `번호 합계는 {합계}이며 과거 기록에서 비교적 높은 구간에 있어요.` | `합계 {합계} · 상위 25% 구간` |
| 합계 상위 10% | `번호 합계는 {합계}이며 과거 당첨 조합 중 높은 쪽 10% 구간에 있어요.` | `합계 {합계} · 상위 10% 구간` |
| 표준편차 하위 10% | `번호들이 비교적 가까운 범위에 모여 있어요.` | `표준편차 {값} · 하위 10%` |
| 표준편차 상위 10% | `번호들이 낮은 수부터 높은 수까지 넓게 퍼져 있어요.` | `표준편차 {값} · 상위 10%` |
| A/C 하위 10% | `번호 사이의 차이값이 서로 겹치는 형태가 많아요.` | `A/C {값} · 하위 10%` |
| A/C 상위 10% | `번호 사이의 차이값이 비교적 다양하게 구성돼 있어요.` | `A/C {값} · 상위 10%` |

## 9. 번호대·끝수·직전 회차·수 성격

| 경우 | 문구 |
|---|---|
| 한 번호대에 3개 이상 | `{번호대} 번호대에 여섯 번호 중 {개수}개가 모여 있어요.` |
| 다섯 번호대에 분산 | `번호가 다섯 개 번호대에 걸쳐 분포해 있어요.` |
| 같은 끝수 2개 | `{번호 A}번과 {번호 B}번은 끝수가 {끝수}로 같아요.` |
| 같은 끝수 3개 이상 | `끝수가 {끝수}로 같은 번호는 {번호들}예요.` |
| 같은 끝수 번호쌍 여러 개 | `같은 끝수로 묶이는 번호쌍이 {개수}개 있어요.` |
| 이월수 1개 | `{번호}번은 직전 {회차}회에도 나온 번호예요.` |
| 이월수 여러 개 | `직전 {회차}회와 같은 번호가 {개수}개 있어요: {번호들}.` |
| 이월수와 이웃수가 함께 있음 | `직전 {회차}회와 같은 번호 {이월수 개수}개, 이웃한 번호 {이웃수 개수}개가 포함돼 있어요.` |
| 이웃수 | `직전 회차 번호와 이웃한 수가 {개수}개 있어요: {번호들}.` |
| 소수 4개 이상 | `여섯 번호 중 소수가 {개수}개예요.` |
| 합성수 5개 이상 | `여섯 번호 중 합성수가 {개수}개예요.` |
| 완전제곱수 2개 이상 | `완전제곱수가 {개수}개 포함돼 있어요: {번호들}.` |
| 3의 배수 4개 이상 | `3의 배수가 {개수}개 포함돼 있어요.` |
| 4·5의 배수 3개 이상 | `{배수}의 배수가 {개수}개 포함돼 있어요.` |

직전 회차 관계와 수 성격은 일반적으로 보조 문장으로 사용한다.

## 10. 중립과 예외

| 경우 | 문구 |
|---|---|
| 유효 회차 0개 | `선택한 기간에는 비교할 과거 회차가 없어요.` |
| 10회 미만 표본, 강한 기록 없음 | `선택 기간이 짧아 출현 차이를 뚜렷한 특징으로 판단하기 어려워요.` |
| 강한 후보 없음 | `뚜렷하게 두드러진 과거 기록은 없어요.` |

중립 문구에도 가능한 경우 홀짝, 저고, 연속, 번호대 등 다른 지표군의 보조 문장 하나를 붙인다. 기존처럼 모든 중립 조합을 `홀짝 n:n, 합계 n인 조합이에요.` 한 문장으로만 처리하지 않는다.

## 11. 선택 규칙

1. 모든 유효 후보를 만든다.
2. 동일 6번호, 5번호 일치는 가장 높은 고정 우선순위를 가진다.
3. 나머지는 기록의 구체성, 반복 강도, 평균 차이와 표본 안정성을 반영한 내부 주목도 점수로 정렬한다.
4. 일정 점수 이상인 가장 높은 후보를 대표 문장으로 선택한다.
5. 대표 문장과 다른 지표군에서 보조 후보 하나를 선택한다.
6. 점수가 같으면 metric과 문구의 고정 순서로 결정해 결과가 무작위로 바뀌지 않게 한다.
7. 유효한 대표 후보가 없으면 중립 문장을 사용한다.

주목도 점수는 화면에 노출하지 않으며 좋은 조합 점수나 당첨 가능성 점수가 아니다.

## 12. 금지 표현

- 나올 때가 됐어요
- 다음 회차에 기대할 수 있어요
- 좋은 조합이에요
- 당첨 가능성이 높아요
- 균형이 좋아요
- 추천할 만한 조합이에요

모든 문구는 선택한 기간의 과거 기록만 설명한다.
