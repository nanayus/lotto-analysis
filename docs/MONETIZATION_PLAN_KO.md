# 수익 모델 계획

## 결론

수익 모델은 `게스트의 리워드 광고`와 `Pro 구독` 두 축으로 운영한다. 별도 분석권, 티켓, 광고 제거팩, 무료회원 등급은 두지 않는다.

## 상품 구조

| 구분 | 게스트 | Pro |
|---|---|---|
| 가격 | 무료 | 구독 |
| 결과 공개 | 매번 리워드 광고 | 광고 없음 |
| 조건 선택 | 최대 2개 | 무제한 + 균형 프리셋 |
| 조합 생성 | 한 번에 최대 2개 | 한 번에 최대 5개 |
| 고급 기능 | 기본 분석 | AI 해설, 같은 조건 다시 뽑기, Custom 기간 |
| 저장 | 기기 저장 | 클라우드 저장·동기화 |

## 전환 설계

Pro는 사용 전부터 장황하게 설명하지 않는다. 사용자가 한도에 닿거나 Pro 기능을 누르는 순간에만 전환점을 보여준다.

- 세 번째 조건 선택: `조건은 2개까지 선택할 수 있어요` + `Pro 살펴보기`
- 광고 결과 화면: `광고 보고 이번 결과 보기`와 `Pro 살펴보기`
- AI 해설·같은 조건 다시 뽑기·Custom 기간: 기능 자리에서 Pro 안내
- 내 번호: 게스트는 `이 기기에만 저장돼요`, Pro는 클라우드 동기화 안내

로그인은 결제 상품이 아니므로 Pro 전환 대신 로그인 혜택을 내세우지 않는다.

## 광고 원칙

- 게스트는 새 분석 결과와 동일 조합 재열람 모두 리워드 광고를 거친다.
- 광고를 끝내면 표준 분석 결과 전체를 공개한다.
- 광고가 준비되지 않으면 테스트 가능한 대체 흐름 또는 명확한 재시도 상태를 제공한다.
- 배너·전면 광고를 화면 곳곳에 추가하지 않는다.

## UX 원칙

- 상품 설명보다 앱 사용을 먼저 허용한다.
- 한 화면에서 한 번만 설명한다.
- 문장보다 상태, 버튼명, 잠금 표시로 정책을 전달한다.
- Pro 가치는 `광고 제거`, `무제한 조건`, `AI`, `클라우드` 네 가지로 압축한다.

## 검증 지표

- 결과 공개 화면 도달률
- 리워드 광고 시작·완료율
- 조건 한도 도달률
- Pro 안내 열람률과 구독 전환율
- 광고 또는 잠금 화면 이탈률
