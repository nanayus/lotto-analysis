# Lotto Insight 수익화 운영 계획

작성 기준일: 2026-09-06

## 1. 결론

당분간 모든 핵심 기능을 무료로 제공하고 분석 결과 진입 전 전면광고만 운영한다. Pro 수익화 코드는 유지하되 결제·잠금 UI는 비활성화한다.

현재 기본값:

- `EXPO_PUBLIC_PRO_PLAN_ENABLED=false`
- `EXPO_PUBLIC_RESULT_ADS_ENABLED=true`
- 핵심 기능 전체 공개
- 지원되는 네이티브 환경에서 결과 전면광고 운영
- Pro 결제 및 잠금 UI 없음

광고 미구성 또는 로드 실패 시 사용자를 막지 않고 결과를 공개한다. Pro는 스토어 상품, 서버 권한과 구매 복원을 검증한 뒤 별도 기능 플래그로 다시 활성화한다.

## 2. 상품 구조

현재 수익모델은 `모든 사용자에게 전체 기능 공개 + 결과 전면광고` 한 축이다. 별도 분석권, 티켓, 광고 제거팩, 무료회원 등급은 두지 않는다. Pro 구독은 향후 선택지로 코드만 보존한다.

| 구분 | 게스트 | Pro |
|---|---|---|
| 가격 | 무료 | 구독 |
| 결과 공개 | 전면광고 경로 | 광고 없이 즉시 |
| 조합 생성 | 한 번에 최대 2개 | 한 번에 최대 5개 |
| 조건 선택 | 현재 코드상 최대 99개 | 무제한 |
| 고급 기능 | 기본 생성·분석 | 균형 프리셋, AI 해설, 같은 조건 다시 뽑기, Custom |
| 저장 | 기기 저장 | 기기 저장, 연결 계정은 클라우드 |

게스트 조건 한도 99개는 현재 코드 상태를 기록한 것이며 최종 상품 결정은 아니다. 기존의 2개 제한 정책은 현재 구현과 불일치하므로 Pro 활성화 전에 다시 확정한다.

## 3. 전환 설계

Pro는 사용 전부터 장황하게 설명하지 않는다. 사용자가 Pro 기능을 누르거나 운영 한도에 닿을 때만 전환점을 보여준다.

- 광고 결과 진입: `광고 보고 이번 결과 보기`와 `Pro 살펴보기`
- 균형 프리셋: 기능 자리에서 Pro 안내
- AI 해설·같은 조건 다시 뽑기·Custom 기간: 해당 기능 자리에서 Pro 안내
- 내 번호: 기본은 `이 기기에만 저장돼요`, 연결 계정은 클라우드 동기화 안내

Apple·Google 계정 연결은 결제 조건이 아니므로 Pro 전환 혜택처럼 설명하지 않는다.

## 4. 광고 원칙

- 전면광고는 분석 결과 진입 시점에만 사용한다.
- 배너 광고를 화면 곳곳에 추가하지 않는다.
- 광고를 닫으면 표준 분석 결과 전체를 공개한다.
- 광고 준비 실패가 핵심 기능의 영구 차단으로 이어지지 않도록 대체 흐름을 제공한다.
- 동일 조합 재열람의 광고 정책도 신규 결과와 일관되게 적용한다.
- 테스트 빌드는 Google 테스트 ID만 사용한다.

## 5. Pro 가치

Pro 가치는 다음 네 범주로 압축한다.

1. 광고 없는 결과 확인
2. 여러 조합과 고급 생성 편의
3. AI 해설·Custom·같은 조건 다시 뽑기
4. 연결 계정의 클라우드 저장

과거 통계 자체를 불필요하게 잘라 판매하지 않는다. Free에서도 제품의 핵심 분석 가치를 이해할 수 있어야 한다.

## 6. 인증과 구매

- 익명 UID는 로그인 화면 없이 RevenueCat 사용자와 서버 권한을 연결하는 내부 식별자로 사용할 수 있다.
- 익명 상태에서도 Pro 구매와 스토어 복원이 가능해야 한다.
- Apple·Google 계정 연결은 구매 조건이 아니다.
- 서버는 AI 해설과 권한이 필요한 요청에서 Pro 상태를 다시 검증한다.
- 로그인, Pro, 클라우드 저장 상태를 각각 독립적으로 표시한다.

## 7. 단계적 활성화

### 단계 A — 기본 공개

- Pro 플래그 OFF
- 계정 연결 플래그 OFF
- 모든 핵심 기능 공개
- 기기 저장
- 필요 시 Firebase Analytics와 익명 UID만 운영

### 단계 B — 광고 검증

- 테스트 전면광고로 준비·완료·실패 흐름 검증
- 결과 진입 이탈률과 광고 실패율 확인
- 운영 광고 ID 적용 전 개인정보·스토어 선언 확인

### 단계 C — Pro 샌드박스

- RevenueCat 상품과 entitlement 연결
- 구매, 복원, 만료, 앱 재설치 시나리오 검증
- 게스트와 Pro UI 차이 확인
- 조건 선택 한도 최종 결정

### 단계 D — 온라인 Pro 기능

- AI Functions와 서버 Secret 배포
- 사용자별 rate limit, 비용 한도, 오류 모니터링
- 계정 연결과 클라우드 마이그레이션 검증
- 초대 코드 운영 정책 확정

## 8. 운영 지표

- 결과 공개 화면 도달률
- 전면광고 준비·시작·완료·실패율
- Pro 안내 열람률
- 구매 시작·완료·실패율
- 구매 복원 성공률
- Pro 기능 사용률
- AI 응답 지연·실패율과 비용
- 계정 연결 및 클라우드 마이그레이션 성공률
- 광고 또는 잠금 화면 이탈률

Analytics가 활성화된 배포에서는 선택·생성한 번호와 조합 요약값이 이용 이벤트로 기록될 수 있다. AI 자유 입력 질문은 Analytics 이벤트로 보내지 않지만, AI 해설 요청 처리에는 질문과 분석 맥락이 서버 및 AI 제공자에 전달될 수 있다.

## 9. 활성화 게이트

다음을 모두 확인하기 전에는 운영형 Pro를 켜지 않는다.

- App Store·Google Play 상품 등록과 심사 문구
- RevenueCat Current Offering과 entitlement
- iOS·Android 샌드박스 구매 및 복원
- AdMob 운영 ID와 실패 fallback
- Firebase Functions 배포 및 Secret
- Firestore 보안 규칙
- 직접 선택 조합의 `manual` 출처 클라우드 저장 검증
- 개인정보처리방침과 데이터 삭제
- AI 비용 경보, rate limit, 장애 대응
- 게스트 조건 선택 한도에 대한 제품 결정
