# Lotto Insight 수익 모델 및 이용 정책

최종 수정: 2026-09-02

## 1. 제품 원칙

Lotto Insight는 예측 서비스가 아니라 과거 당첨 데이터를 탐색하는 앱이다.

수익 모델은 무료 결과를 고의로 훼손하는 방식이 아니라 다음 가치에 과금한다.

1. 광고 없이 바로 보는 속도
2. AI 해설과 조합 비교 같은 분석 깊이
3. 클라우드 저장과 기기간 동기화 같은 관리 편의

무료 사용자가 리워드 광고를 완료했다면 표준 분석 결과를 빠짐없이 공개한다. 결과 카드 일부를 흐리거나 임의로 잠그지 않는다.

## 2. 사용자 등급

앱의 이용 상태는 `게스트`, `무료회원`, `Pro` 세 가지다. 분석권, 티켓, 일간·주간 분석 횟수는 운영하지 않는다.

회원유형별 세부 조건과 화면 표현 기준은 [회원유형별 이용 정책](./MEMBERSHIP_TIER_POLICY_KO.md)을 기준으로 한다.

| 항목 | 게스트 | 무료회원 | Pro |
|---|---|---|---|
| 계정 | 없음 | 로그인 | 로그인·구독 |
| 한 번에 만들 조합 | 최대 2개 | 최대 5개 | 최대 5개 |
| 기본 번호 생성 | 가능 | 가능 | 가능 |
| 기본 조합 분석 | 가능 | 가능 | 가능 |
| 새 결과 공개 | 리워드 광고 후 | 리워드 광고 후 | 즉시 공개 |
| 같은 조합 재열람 | 다시 광고 후 | 다시 광고 후 | 즉시 공개 |
| 표준 분석 결과 | 전체 공개 | 전체 공개 | 전체 공개 |
| 기본 기간 프리셋 | 가능 | 가능 | 가능 |
| 회차 범위 직접 선택 | 불가 | 불가 | 가능 |
| 두 조합 비교 | 불가 | 불가 | 가능 |
| AI 조합 해설·추가 질문 | 불가 | 불가 | 가능 |
| 내 번호 저장 | 불가 | 기기 저장 | 클라우드 저장 |
| 즐겨찾기·구매 표시 | 불가 | 기기 저장 | 클라우드 저장 |
| 기기간 동기화·복원 | 불가 | 불가 | 가능 |
| 광고 | 결과마다 리워드 광고 | 결과마다 리워드 광고 | 없음 |

`최대 2개`, `최대 5개`는 앱 사용 횟수가 아니라 한 번의 번호 생성 흐름에서 동시에 만들 수 있는 조합 수다.

## 3. 표준 분석 결과

게스트와 무료회원도 광고를 완료하면 다음 표준 결과를 모두 본다.

- 선택한 여섯 번호
- 과거 당첨 등위 상당 기록
- 주번호 일치 개수 분포
- 번호별 출현 횟수와 순위
- 홀짝, 합계, 연속번호 형태
- 2~6개 하위 조합 출현 통계
- 선택 번호군과 전체 번호 평균 비교
- 기본 기간 프리셋과 보너스 포함 필터

표준 결과를 Pro 전환 유도를 위해 부분적으로 가리지 않는다.

## 4. 리워드 광고

### 4.1 노출 시점

- 사용자가 `분석하기`를 눌러 결과 공개를 요청할 때 노출한다.
- 내번호보기에서 이전 조합의 결과를 다시 열 때도 노출한다.
- 광고를 미리 보고 이용권을 적립하는 구조는 사용하지 않는다.
- 배너 광고와 강제 전면 광고는 사용하지 않는다.

### 4.2 결과 공개 화면

버튼 우선순위는 다음과 같다.

1. `Pro 살펴보기`
2. `광고 보고 이번 결과 보기`
3. 텍스트 버튼 `다음에 하기`

광고 완료 후 현재 선택한 결과만 공개한다. 광고 완료를 이유로 결과 일부를 다시 잠그지 않는다.

### 4.3 실패 처리

- 광고 재고 없음, SDK 오류, 사용자 중단 시 결과를 공개하지 않는다.
- 실패를 결제 오류처럼 표현하거나 Pro 결제를 강요하지 않는다.
- `광고를 준비하지 못했어요. 잠시 후 다시 시도해 주세요.`처럼 상태를 설명한다.
- Pro와 `다음에 하기`는 항상 선택 가능해야 한다.

### 4.4 구현 전제

현재 저장소에는 AdMob SDK와 실제 광고 단위 ID가 없다. 화면과 접근 정책은 먼저 반영하되, 운영 광고 공개는 다음 준비가 완료된 뒤 활성화한다.

- Google Mobile Ads SDK
- iOS·Android AdMob App ID
- 플랫폼별 Rewarded Ad Unit ID
- 개발·운영 환경 분리
- 서버 측 보상 검증과 중복 거래 방지

## 5. Pro 상품

Pro의 핵심 메시지는 `무제한 분석`이 아니다. 무료에도 사용 횟수 제한이 없기 때문이다.

권장 메시지:

> 광고 없이 더 깊게 분석하고, 모든 기기에서 이어보세요.

Pro 혜택은 다음 다섯 가지로 고정한다.

1. 모든 분석 결과 광고 제거
2. AI 조합 해설과 추가 질문
3. 두 조합 비교
4. 회차 범위 직접 선택
5. 내 번호 클라우드 저장과 기기간 동기화

초기 가격 가안:

- 월간 ₩4,900
- 연간 ₩39,000

실제 판매 문구와 가격은 App Store, Google Play, RevenueCat 상품이 연결된 뒤 확정한다.

## 6. 저장 정책

### 게스트

- 생성 결과를 자동 또는 수동으로 저장하지 않는다.
- 내번호보기에서는 로그인 이점을 설명한다.

### 무료회원

- 로그인 계정별 로컬 저장소에 저장한다.
- 화면에 `이 기기에만 저장돼요`를 명확히 표시한다.
- 앱 삭제, 기기 변경 시 복원되지 않을 수 있음을 과장 없이 안내한다.

### Pro

- 사용자별 클라우드 컬렉션에 저장한다.
- 기존 로컬 데이터를 Pro 전환 시 클라우드로 병합한다.
- 동기화 중 중복 ID를 정규화한다.
- Pro 종료 시 클라우드 데이터를 삭제하지 않는다.
- 현재 기기의 로컬 사본은 계속 볼 수 있다.

## 7. 화면별 적용

### 공통 상단바

- 티켓 아이콘과 잔액을 제거한다.
- 게스트·무료회원에게 `Pro` 진입점을 제공한다.
- Pro 이용 중에는 `PRO` 상태를 표시한다.

### 번호뽑기

- 게스트 선택지는 1게임, 2게임이다.
- 무료회원·Pro 선택지는 1게임, 3게임, 5게임이다.
- 조건 선택과 기본 번호 생성 자체는 무료로 유지한다.

### 조합 분석

- 결과를 보기 직전 광고 또는 Pro 선택 화면을 표시한다.
- Pro는 같은 흐름을 거치지 않고 바로 결과를 연다.
- 회차 직접 선택과 조합 비교에는 `PRO` 표시를 붙인다.
- AI 해설은 잠금 이유와 얻는 가치를 함께 설명한다.

### 내번호보기

- 게스트에게 빈 저장 목록을 만들지 않고 로그인 안내 화면을 보여준다.
- 무료회원에게 기기 저장 상태를 표시한다.
- Pro에게 클라우드 동기화 상태를 표시한다.
- 무료회원의 재열람 버튼은 `광고 후 결과 보기`로 표현한다.
- Pro의 재열람 버튼은 `결과 보기`로 표현한다.

### 환경설정

- 분석 횟수, 티켓, 주간 갱신 정보를 제거한다.
- 현재 등급과 실제 저장 방식을 표시한다.
- 무료회원에게 광고, 기기 저장을 설명한다.
- Pro에게 광고 제거, AI, 비교, 직접 선택, 클라우드 혜택을 설명한다.

### 로그인

- `무료 분석 횟수 지급`이나 `다른 기기 복원`을 무료회원 혜택으로 말하지 않는다.
- `최대 5개 조합`, `이 기기에 번호 저장`을 로그인 가치로 설명한다.

## 8. 초대 기능

분석권이 제거되었으므로 `친구 +1회, 초대자 +5회` 보상은 더 이상 성립하지 않는다.

초대 코드 데이터와 서버 코드는 당장 삭제하지 않지만 사용자 화면에서는 숨긴다. Pro 무료 기간은 앱의 낮은 월간 사용 빈도 때문에 구독 가치를 쉽게 대체할 수 있으므로 자동으로 전환하지 않는다.

초대 기능을 다시 출시하려면 다음 중 하나를 별도로 검증한 뒤 정책을 새로 승인한다.

- 비금전적 배지나 공유 기능
- 제한된 시즌 이벤트
- 광고 없이 결과 보기 1회처럼 적립되지 않는 즉시성 보상

## 9. 금지하는 제한

- 표준 분석 결과 일부 블러 처리
- 무료회원만 인위적으로 느린 계산 또는 애니메이션
- 기본 번호 통계 잠금
- 광고 완료 후 추가 Pro 잠금
- 저장 데이터를 예고 없이 삭제
- `AI 뽑기` 명칭을 미래 당첨 예측처럼 설명
