작성 기준일: 2026-08-30  
대상 플랫폼: iOS, Android, Mobile Web

## 1. 목적과 결론

이 문서는 Lotto Insight의 무료 이용, 분석권, Pro 구독, 리워드 광고, 친구 초대를 하나의 일관된 수익 구조로 정의한다. 제품·디자인·개발·운영 담당자가 별도 해석 없이 구현하고 성과를 측정할 수 있는 수준을 목표로 한다.

최종 수익 구조는 다음과 같다.

```text
무료 통계 탐색
↓
제한적으로 제공되는 완전한 조합 분석
↓
더 분석하려는 사용자는 리워드 광고 또는 친구 초대
↓
반복 분석·비교·자동화를 원하는 사용자는 Pro 구독
```

핵심 결정:

- 주 수익원은 월간·연간 **Pro 구독**이다.
- 리워드 광고는 무료 사용자의 추가 분석을 위한 보조 수익원이다.
- 분석권은 별도 요금제가 아니라 무료 사용자가 소비하는 이용 단위다.
- 분석권을 사용한 보고서에는 핵심 결과를 다시 Pro로 잠그지 않는다.
- Pro는 결과 일부를 숨기는 상품이 아니라 무제한 사용, 비교, 자동화, 저장을 제공하는 상품이다.
- 초기 버전에는 유료 분석권 묶음, 광고 제거팩, Lifetime 상품을 출시하지 않는다.
- 배너·전면 광고는 사용하지 않고 사용자가 직접 선택하는 리워드 광고만 사용한다.

## 2. 수익모델 원칙

### 2.1 과거 데이터 분석에 비용을 지불한다

사용자가 돈을 지불하는 대상은 당첨 가능성이나 추천 번호가 아니다. 다음 가치에 비용을 지불한다.

- 많은 조합을 횟수 제한 없이 분석하는 편의
- 서로 다른 조합을 같은 조건에서 비교하는 기능
- 새 회차가 추가됐을 때 저장 조합을 자동으로 다시 분석하는 기능
- 조합과 분석 결과를 여러 기기에서 관리하는 기능
- Custom 기간, 일괄 분석 등 반복 사용자를 위한 고급 도구

### 2.2 한 번 해제한 가치는 보존한다

- 분석권으로 연 보고서는 이후에도 다시 볼 수 있다.
- Pro가 종료되어도 기존 보고서와 저장 조합을 삭제하지 않는다.
- 같은 조합과 같은 데이터 버전에 대한 재시도에는 분석권을 다시 차감하지 않는다.
- 앱 오류로 결과 표시가 실패해도 이미 승인된 보고서는 재열람할 수 있다.

### 2.3 무료 사용자도 제품의 핵심 가치를 이해할 수 있어야 한다

- 번호별 통계와 종합 통계는 로그인 없이 탐색할 수 있다.
- 첫 분석 전까지 가입이나 결제를 강요하지 않는다.
- 가입 후 제공되는 웰컴 분석권으로 완전한 조합 분석을 경험하게 한다.
- Paywall은 앱 실행 직후가 아니라 고급 기능 선택 또는 분석 가능 횟수 소진 시 노출한다.

### 2.4 제품을 광고 경제처럼 보이게 하지 않는다

- 화면 상단에 분석권 잔액을 상시 노출하지 않는다.
- 분석이 필요한 맥락에서만 남은 횟수와 선택지를 보여준다.
- 광고를 보도록 압박하는 카피, 카운트다운, 강제 전면 광고를 사용하지 않는다.
- 사용자가 광고 대신 다음 주 무료 분석을 기다리거나 Pro를 선택할 수 있게 한다.

## 3. 상품 구조

실제 회원 등급은 `FREE`와 `PRO` 두 가지다. `분석권`은 FREE 사용자의 조합 분석을 승인하는 소비 단위다.

| 기능 | 무료·분석 가능 횟수 없음 | 무료·분석권 사용 | Pro |
|---|---:|---:|---:|
| 번호별 통계 | 무제한 | 무제한 | 무제한 |
| 종합 통계 | 무제한 | 무제한 | 무제한 |
| 번호 선택·랜덤 생성 | 가능 | 가능 | 가능 |
| 조건 기반 번호 생성 | 가능 | 가능 | 가능 |
| 홀짝·합계·연속 번호 미리보기 | 제공 | 제공 | 제공 |
| 새로운 조합의 과거 분석 | 불가 | 조합 1개 | 무제한 |
| 당첨 등위 상당 기록 | 미리보기 | 전체 제공 | 전체 제공 |
| 본번호 일치 분포 | 미리보기 | 전체 제공 | 전체 제공 |
| 번호별 출현 통계 | 미리보기 | 전체 제공 | 전체 제공 |

| 프리셋 기간·Bonus 필터 | 기존 보고서에서 제공 | 제공 | 제공 |
| Custom 기간 | 불가 | 불가 | 제공 |
| 조합 A/B 비교 | 불가 | 불가 | 제공 |

| 클라우드 동기화 | 불가 | 불가 | 제공 |
| 리워드 광고 | 선택 가능 | 선택 가능 | 노출하지 않음 |

### 3.1 무료 미리보기

분석 가능 횟수가 없는 사용자가 여섯 번호를 선택하면 다음 항목까지는 무료로 보여준다.

- 선택한 여섯 번호
- 홀짝 비율
- 번호 합계
- 연속 번호 그룹
- 분석하면 확인할 수 있는 항목 목록

역대 당첨 등위, 일치 분포, 출현 빈도, 하위조합 빈도의 실제 결과는 분석 승인 후 보여준다. 잠긴 숫자를 흐리게 노출하거나 가짜 결과를 사용하지 않는다.

### 3.2 분석권으로 해제되는 표준 보고서

분석권 1회는 새로운 6개 번호 조합 하나의 표준 보고서를 해제한다. 보고서에는 다음 항목을 모두 포함한다.

- 선택 번호와 활성 분석 범위
- 최고 본번호 일치 개수
- 1~5등 상당 기록 요약과 전체 기록
- 본번호 일치 개수 0~6 분포
- 여섯 번호 각각의 출현 횟수와 순위
- 홀짝, 합계, 연속 번호
- 2~6개 모든 하위조합의 빈도와 최근 출현
- 선택 여섯 번호 평균과 전체 번호 평균 비교

보고서를 해제한 뒤 프리셋 기간 또는 Bonus 필터를 변경하는 것은 추가 차감 없이 허용한다. Custom 기간, A/B 비교, 일괄 분석은 Pro 도구로 유지한다.

### 3.3 Pro가 제공하는 가치

Pro는 다음 사용자를 대상으로 한다.

- 매주 여러 조합을 분석하는 사용자
- 여러 조합을 직접 비교하는 사용자
- 분석 기간을 세밀하게 조정하는 사용자
- 저장한 조합이 새 회차에서 어떻게 달라졌는지 계속 확인하는 사용자

Pro 혜택:

- 새로운 조합 분석 무제한
- Custom 기간 분석
- 조합 A/B 비교
- 최대 5개 조합 일괄 분석
- 새 회차 추가 시 저장 조합 자동 재분석
- 최대 200개 조합 저장과 클라우드 동기화
- 모든 리워드 광고 제거

## 4. 분석 가능 횟수 정책

무료 사용자의 분석 기회는 세 종류로 관리한다.

### 4.1 웰컴 분석권

- 플랫폼 로그인과 계정 생성 완료 시 3회 지급한다.
- 만료되지 않는다.
- 한 계정당 한 번만 지급한다.
- 보너스 분석권 잔액에 포함한다.

### 4.2 주간 무료 분석

- 매주 일요일 00:00 `Asia/Seoul` 기준으로 1회를 제공한다.
- 주간 무료 분석은 다음 주로 이월되지 않는다.
- 보너스 분석권보다 먼저 사용한다.
- 서버시간과 서버 상태를 기준으로 판단한다.

### 4.3 보너스 분석권

- 친구 초대로 획득한다.
- 계정에 귀속되며 양도하거나 현금·상품·실제 복권과 교환할 수 없다.
- 만료되지 않는다.
- 최대 10회까지만 보유할 수 있다.
- 잔액이 10회인 사용자는 추가 친구 초대 보상을 받지 못하므로 초대 전에 이를 명확히 알린다.

### 4.4 차감 우선순위

```text
Pro 활성 → 차감 없음
주간 무료 분석 보유 → 주간 무료 분석 사용
보너스 분석권 보유 → 보너스 분석권 1회 차감
둘 다 없음 → 리워드 광고 또는 Pro 선택
```

### 4.5 같은 조합의 처리

- 조합 번호는 오름차순 정규화 후 해시한다.
- `사용자 + 조합 해시 + 데이터 버전`이 같으면 이미 해제된 보고서로 판단한다.
- 앱 재설치, 네트워크 재시도, 분석 화면 재진입에는 추가 차감하지 않는다.
- 새 추첨 데이터가 반영되어 데이터 버전이 달라지면 무료 사용자는 새 분석으로 간주한다.
- Pro 사용자는 새 데이터 버전에서도 자동으로 해제한다.

## 5. 리워드 광고 정책

### 5.1 기본 규칙

- 리워드 광고 1회 완료 시 현재 선택한 조합의 표준 보고서 1개를 해제한다.
- 광고 시청권을 미리 적립하지 않는다.
- 한 계정당 주 최대 3회까지 사용할 수 있다.
- 10분 쿨다운은 두지 않는다.
- 한 광고가 성공적으로 끝난 뒤 다음 광고를 요청할 수 있다.
- 광고 미로딩, 중단, SDK 오류, SSV 검증 실패에는 보고서를 해제하지 않으며 한도를 차감하지 않는다.
- Pro 사용자에게는 광고 버튼과 광고 관련 카피를 노출하지 않는다.

### 5.2 광고가 없는 경우

광고 재고가 없거나 로딩에 실패하면 다음 선택지를 제공한다.

- 잠시 후 다시 시도
- 다음 주 무료 분석 기다리기
- Pro 살펴보기

광고 실패를 결제로 압박하는 오류처럼 표현하지 않는다.

### 5.3 광고 보상 검증

- AdMob Rewarded Ads의 Server-Side Verification을 사용한다.
- 광고 거래 ID를 유일 키로 저장해 중복 콜백을 무시한다.
- 클라이언트 완료 콜백만으로 보고서를 영구 해제하지 않는다.
- 검증 지연이 발생하면 `광고 확인 중` 상태를 표시하고 확인 후 자동으로 보고서를 연다.

## 6. 친구 초대 정책

### 6.1 보상

| 대상 | 보상 |
|---|---|
| 초대받은 사용자 | 기존 웰컴 3회에 보너스 분석권 1회 추가 |
| 초대한 사용자 | 보너스 분석권 2회 |

Pro 기간은 초대 보상으로 제공하지 않는다. 주간 사용 빈도가 낮은 제품에서 무료 Pro 기간을 반복 지급하면 구독을 대체할 가능성이 높기 때문이다.

### 6.2 성공 조건

다음 조건을 모두 충족하면 성공한 초대로 처리한다.

- 초대받은 사용자가 신규 계정이다.
- 계정 생성 전에 초대 링크 또는 코드를 적용했다.
- 플랫폼 로그인을 완료했다.
- 첫 번째 조합 분석을 정상적으로 완료했다.
- 자기 초대, 동일 계정 재가입, 이미 보상된 기기와 같은 명백한 부정 패턴이 아니다.

가입만 하고 분석하지 않은 계정에는 양쪽 모두 보상하지 않는다.

### 6.3 제한과 부정 사용 방지

- 초대한 사용자는 월 최대 5명의 성공 보상만 받을 수 있다.
- 초대받은 사용자는 하나의 초대 코드만 적용할 수 있다.
- 보상은 서버 원장에 멱등 거래로 한 번만 기록한다.
- 동일 기기에서 반복 생성된 계정, 비정상적으로 빠른 가입·분석, 다량의 동일 네트워크 가입은 위험 신호로 기록한다.
- 초기에는 자동 차단보다 보상 보류와 운영 검토를 우선한다.

### 6.4 사용자 카피

```text
친구가 첫 분석을 완료하면
친구는 분석 1회, 나는 분석 2회를 받아요.
```

보상 조건, 월 한도, 보유 한도는 초대 화면에서 링크 없이 확인할 수 있게 표시한다.

## 7. Pro 상품과 가격

### 7.1 출시 상품

| 상품 | 초기 가격 | 비고 |
|---|---:|---|
| Pro 월간 | ₩4,900 | 자동 갱신 |
| Pro 연간 | ₩39,000 | 월간 12개월 대비 약 34% 할인 |

초기에는 무료 체험을 붙이지 않는다. 웰컴 분석권 3회가 제품 체험 역할을 담당한다.

출시하지 않는 상품:

- 주간 구독
- 유료 분석권 묶음
- 광고 제거팩
- Lifetime Pro
- Pro보다 높은 별도 등급

### 7.2 Paywall 노출 시점

Paywall은 다음 맥락에서만 노출한다.

- 무료 분석 가능 횟수가 없는 상태에서 `분석하기`를 누름
- Custom 기간을 선택함
- A/B 비교를 시작함
- 여러 조합 일괄 분석을 선택함
- 여섯 번째 저장 이후 저장을 시도함
- 설정에서 사용자가 직접 `Pro`를 선택함

첫 앱 실행, 번호별 통계 탐색, 가입 직후에는 전체 화면 Paywall을 노출하지 않는다.

### 7.3 Paywall 정보 구조

```text
PRO
```

### 7.4 구독 종료

- 결제 유예 기간에는 스토어와 RevenueCat 상태를 따른다.
- 만료 후 새 분석은 무료 정책을 적용한다.
- 기존 보고서와 저장 조합은 읽기 전용으로 보존한다.
- 무료 저장 한도인 5개를 초과한 조합을 삭제하지 않는다.
- 사용자는 기존 조합을 볼 수 있지만 여섯 번째 이후 새 저장은 할 수 없다.
- 보유 보너스 분석권은 그대로 유지한다.

## 8. 로그인과 계정

### 8.1 로그인 시점

- 번호별 통계, 종합 통계, 번호 선택은 로그인 없이 사용할 수 있다.
- 첫 번째 과거 조합 분석을 시작할 때 로그인을 요구한다.
- 로그인 화면에는 분석권과 결과 복원에 계정이 필요한 이유를 설명한다.

### 8.2 로그인 수단

- iOS: Apple 로그인 기본, Google 로그인 보조
- Android: Google 로그인 기본, Apple 로그인 보조
- Web: Apple 로그인과 Google 로그인
- 두 로그인 수단을 같은 앱 계정에 명시적으로 연결할 수 있게 한다.
- 이메일 주소가 같다는 이유만으로 계정을 자동 병합하지 않는다.

### 8.3 계정 삭제

- 앱 설정에서 계정 삭제를 시작하고 완료할 수 있게 한다.
- 웹사이트에도 앱 없이 요청할 수 있는 계정 삭제 페이지를 제공한다.
- 삭제 전 구독은 스토어에서 별도로 취소해야 한다는 점을 명확히 안내한다.
- 법적·부정 사용 방지 목적으로 일부 거래 식별자를 보존한다면 보존 항목과 기간을 개인정보처리방침에 명시한다.

## 9. 결제·광고·서버 구성

### 9.1 권장 구성

- 인증·DB·서버 함수: 기존 Firebase Auth, Firestore, Cloud Functions
- 네이티브 구독: RevenueCat + App Store In-App Purchase + Google Play Billing
- 광고: Google AdMob Rewarded Ads + SSV
- 앱: 기존 Expo Router·React Native 구조 유지
- 분석 계산: 현재 순수 도메인 로직 유지
- 권한과 사용량 판단: 서버가 최종 권위 보유

현재 저장소에 구현된 Firebase 인증·동기화 구조를 확장한다. 클라이언트가 분석권과 Pro 권한의 원장이 되어서는 안 된다.

### 9.2 최소 데이터 모델

```ts
type AccessTier = "FREE" | "PRO";

type AccessState = {
  tier: AccessTier;
  proExpiresAt: string | null;
  weeklyFreeAvailable: boolean;
  bonusAnalysisCredits: number;
  rewardedUnlocksUsedThisWeek: number;
  rewardedUnlocksLimit: 3;
  nextWeeklyResetAt: string;
};

type AnalysisUnlock = {
  userId: string;
  combinationKey: string;
  dataVersion: string;
  source: "PRO" | "WEEKLY_FREE" | "BONUS_CREDIT" | "REWARDED_AD";
  unlockedAt: string;
};
```

주요 테이블:

- `users`: 앱 사용자와 계정 상태
- `auth_identities`: Apple·Google 로그인 연결
- `entitlements`: Pro 권한과 원본 결제 식별자
- `credit_ledger`: 웰컴·초대·조정·차감 내역
- `analysis_unlocks`: 해제된 조합과 데이터 버전
- `rewarded_ad_transactions`: 광고 거래 ID와 검증 상태
- `referrals`: 초대자, 피초대자, 진행 상태와 보상 상태
- `lotto_data_versions`: 분석 데이터 버전과 최신 회차

### 9.3 최소 API

```text
GET  /v1/me/access-state
POST /v1/analysis/authorize
POST /v1/rewarded-ads/prepare
POST /v1/admob/ssv
POST /v1/referrals/apply
GET  /v1/referrals/status
POST /v1/revenuecat/webhook
POST /v1/account/link-identity
DELETE /v1/account
```

`POST /v1/analysis/authorize`는 다음 중 하나를 반환한다.

- `UNLOCKED_EXISTING`: 이미 해제된 동일 보고서
- `AUTHORIZED_PRO`: Pro 권한으로 승인
- `AUTHORIZED_WEEKLY`: 주간 무료 분석으로 승인
- `AUTHORIZED_CREDIT`: 보너스 분석권 차감 후 승인
- `REWARD_OR_PRO_REQUIRED`: 광고 또는 Pro 선택 필요

### 9.4 오프라인 처리

- 번호별 통계와 이미 기기에 저장된 보고서는 오프라인에서도 볼 수 있다.
- 새로운 유료·무료 조합 분석 승인은 서버 연결이 필요하다.
- 네트워크가 없으면 분석권을 로컬에서 먼저 차감하지 않는다.
- `연결 후 분석할 수 있어요`라는 차분한 상태를 표시한다.

### 9.5 플랫폼별 차이

- iOS·Android는 네이티브 스토어 결제와 AdMob 리워드 광고를 지원한다.
- Web에서는 AdMob 리워드 광고를 제공하지 않는다.
- Web 무료 사용자는 주간 무료 분석과 친구 초대 보너스만 사용하거나 Pro를 구매한다.
- 동일한 앱 사용자 ID에 연결된 Pro 권한은 플랫폼 간 공유한다.
- 네이티브 앱에서 웹 결제를 더 저렴한 대안으로 유도하지 않는다.

## 11. 매출 가정과 손익 관점

### 11.1 초기 가격 가정

스토어 수수료와 세금을 제외하기 전 소비자 가격을 기준으로 한다.

- 월간 Pro: ₩4,900
- 연간 Pro의 월 환산: ₩3,250
- 예상 혼합 월매출은 월간·연간 선택 비중에 따라 달라진다.

### 11.2 예시 시나리오

아래 수치는 예측이 아니라 수익 구조를 비교하기 위한 가정이다.

| 지표 | 보수적 | 기준 | 성장 |
|---|---:|---:|---:|
| MAU | 10,000 | 50,000 | 100,000 |
| 유료 전환율 | 1.0% | 2.0% | 3.0% |
| 유료 사용자 | 100 | 1,000 | 3,000 |
| 월간 상품 기준 총 결제액 | ₩490,000 | ₩4,900,000 | ₩14,700,000 |
| 15% 스토어 수수료 후 | 약 ₩416,500 | 약 ₩4,165,000 | 약 ₩12,495,000 |

광고 매출 공식:

```text
월 리워드 광고 매출 = 월 완료 광고 노출 수 × 실제 eCPM ÷ 1,000
```

예를 들어 월 24,000회의 완료 노출과 eCPM ₩10,000을 가정하면 광고 총매출은 약 ₩240,000이다. 실제 eCPM, 광고 채움률, 플랫폼 비중은 출시 후 AdMob 데이터로 교체한다.

### 11.3 판단 원칙

- 광고 매출을 위해 무료 분석 횟수를 과도하게 줄이지 않는다.
- Pro 전환율보다 첫 분석 완료율과 4주 재방문율이 먼저다.
- 유료 전환이 낮아도 리워드 광고와 자연 유입이 사용자 획득 비용을 감당하면 무료층을 유지할 수 있다.
- 유료 분석권 묶음은 `구독은 싫지만 분석권을 사고 싶다`는 행동 데이터가 충분히 확인된 뒤 검토한다.

## 13. 출시 단계

### Phase 0 — 무과금 기준선 수집, 2주

- 첫 분석 완료율, 주간 재방문율, 조합당 재열람률을 측정한다.
- 결제 없이 Paywall 후보 진입점의 클릭 의향을 측정한다.
- 개인정보처리방침, 이용약관, 분석 고지 문구를 정비한다.

### Phase 1 — 계정·원장, 2주

- Apple·Google 로그인과 계정 연결을 구현한다.
- 서버 권한, 분석권 원장, 보고서 해제를 구현한다.
- 앱 내·웹 계정 삭제를 구현한다.
- 웰컴 3회와 주간 무료 1회를 적용한다.

### Phase 2 — Pro 결제, 2주

- App Store·Google Play 상품을 생성한다.
- RevenueCat entitlement와 webhook을 연결한다.
- Paywall, 구매, 복원, 구독 관리 진입을 구현한다.
- 만료·환불·결제 유예 상태를 검증한다.

### Phase 3 — 리워드 광고·초대, 2주

- AdMob 리워드 광고와 SSV를 적용한다.
- 주 3회 제한과 광고 실패 처리를 구현한다.
- 초대 링크, 성공 조건, 양쪽 보상, 월 한도를 구현한다.
- 부정 사용 모니터링 화면 또는 운영 쿼리를 준비한다.

### Phase 4 — 점진 출시, 2~4주

- 내부 테스트와 스토어 샌드박스 검증을 완료한다.
- 신규 사용자 10%에 먼저 적용한다.
- 결제·차감 오류가 없으면 50%, 이후 100%로 확대한다.
- 각 단계에서 첫 분석 완료율과 W2 유지율 하락 여부를 확인한다.

## 14. 출시 승인 기준

기능 기준:

- 같은 분석 요청에서 분석권이 두 번 차감되지 않는다.
- 광고 SSV 거래가 중복 보상되지 않는다.
- Pro 사용자는 어떤 분석 흐름에서도 광고를 요구받지 않는다.
- 구매 직후 원래 시도하던 기능이 즉시 열린다.
- 구매 복원 후 다른 기기에서도 Pro가 활성화된다.
- 구독 종료 후 기존 보고서가 사라지지 않는다.
- 한국시간 주간 초기화가 자정 경계와 일광절약시간 여부에 관계없이 정확하다.
- 계정 삭제 후 개인 데이터와 연결된 분석 기록이 정책대로 삭제된다.

사업 기준:

- 수익화 적용 후 첫 분석 완료율이 기준선 대비 15% 이상 하락하지 않는다.
- W4 분석 사용자 유지율이 기준선 대비 10% 이상 하락하지 않는다.
- D35 설치 대비 유료 전환율 목표는 초기 2%로 둔다.
- 광고 시작 대비 정상 완료율, SSV 성공률, 결제 실패율을 플랫폼별로 모니터링한다.
- 구독과 광고를 합친 사용자당 순매출이 무과금 대조군보다 증가한다.

2% 전환율은 보장 수치가 아니라 초기 실험 기준이다. 실제 판단은 유입 경로와 한국 사용자 코호트별 데이터로 한다.

## 16. 정책 준수

- 앱 기능과 Pro 구독 같은 디지털 상품은 네이티브 스토어의 인앱결제로 판매한다.
- 구독은 최신 회차 업데이트, 자동 재분석, 클라우드 저장처럼 지속적인 가치를 제공한다.
- 자동 갱신 조건, 가격, 결제 주기와 취소 방법을 Paywall에서 명확히 표시한다.
- Apple·Google 로그인과 계정 생성이 있으면 앱 및 웹 계정 삭제 경로를 제공한다.
- 리워드 광고의 보상은 동일 사용자에게 귀속되고 양도·현금화할 수 없게 한다.
- 광고 신고 경로, 개인정보 처리와 광고 개인화 동의 흐름을 제공한다.
- 실제 복권 구매, 당첨금, 베팅, 현금성 보상은 앱에서 취급하지 않는다.
- 앱 설명과 화면은 과거 통계가 미래 결과를 예측하지 않는다는 점을 지속적으로 알린다.

- FREE / PRO 두 등급
