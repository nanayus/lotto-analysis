# 회원유형별 이용 정책

최종 수정: 2026-09-02

## 1. 문서 목적

이 문서는 Lotto Insight의 회원유형별 기능 범위와 제한 기준을 정의한다.

회원유형은 게스트, 무료회원, Pro 세 가지다.

분석권, 티켓, 일간·주간 분석 횟수는 운영하지 않는다.

## 3. 조합 개수의 의미

최대 2개, 최대 5개는 하루 또는 계정의 이용 횟수가 아니다.

한 번의 번호 생성 흐름에서 동시에 만들고 확인할 수 있는 조합의 개수를 의미한다.

- 게스트: 1게임 또는 2게임 선택
- 무료회원: 1게임, 3게임 또는 5게임 선택
- Pro: 1게임, 3게임 또는 5게임 선택

분석을 몇 번 했는지는 별도로 세거나 차감하지 않는다.

## 4. 결과 공개 정책

### 게스트·무료회원

- 조합 선택과 번호 생성 단계에서는 광고를 요구하지 않는다.
- 사용자가 결과를 보려는 시점에 리워드 광고를 요청한다.
- 광고를 완료하면 표준 분석 결과 전체를 공개한다.
- 같은 조합을 다시 열어도 광고를 다시 요청한다.
- 광고 완료 뒤 결과 일부를 흐리거나 Pro 전용으로 잠그지 않는다.

### Pro

- 새 분석과 이전 분석 결과를 광고 없이 바로 연다.
- 표준 분석 결과에 더해 Pro 전용 심화 기능을 사용할 수 있다.

## 5. 표준 분석과 Pro 기능

광고를 완료한 게스트·무료회원에게 제공하는 표준 분석:

- 선택한 여섯 번호
- 과거 당첨 등위 상당 기록
- 주번호 일치 개수 분포
- 번호별 출현 횟수와 순위
- 홀짝, 합계, 연속번호 형태
- 하위 조합 출현 통계
- 선택 번호군과 전체 번호 평균 비교
- 기본 기간 프리셋과 보너스 포함 필터

Pro에만 제공하는 심화 기능:

- 광고 없이 결과 보기
- AI 조합 해설
- AI 추가 질문
- 두 조합 비교
- 회차 범위 직접 선택
- 클라우드 저장
- 기기간 동기화와 복원

Pro는 무료 결과를 단순히 잠금 해제하는 상품이 아니라 분석의 깊이와 관리 편의를 높이는 상품으로 정의한다.

## 6. 저장 정책

### 게스트

- 내 번호를 저장하지 않는다.
- 내번호보기 진입 시 로그인으로 얻는 이점을 설명한다.

### 무료회원

- 로그인 계정별로 현재 기기의 로컬 저장소에 저장한다.
- 화면에 “이 기기에만 저장돼요”를 표시한다.
- 앱 삭제나 기기 변경 시 복원되지 않을 수 있다.

### Pro

- 사용자 계정의 클라우드 저장소에 저장한다.
- 현재 기기의 기존 로컬 번호를 Pro 전환 시 클라우드에 병합한다.
- 여러 기기에서 같은 저장 목록을 동기화한다.
- Pro가 종료되어도 기존 클라우드 데이터를 즉시 삭제하지 않는다.
- 현재 기기에 남아 있는 로컬 사본은 계속 확인할 수 있다.

## 7. 화면 표현 기준

### 상단바

- 게스트·무료회원: Pro 진입점 표시
- Pro: PRO 이용 상태 표시
- 티켓 아이콘, 분석권 잔액, 갱신 횟수는 표시하지 않음

### 결과 공개 화면

표시 순서:

1. Pro 살펴보기
2. 광고 보고 이번 결과 보기
3. 텍스트 버튼 다음에 하기

### 내번호보기

- 게스트: 로그인 안내
- 무료회원: 기기 저장 안내와 광고 후 결과 보기
- Pro: 클라우드 동기화 안내와 결과 보기

### 환경설정

- 현재 회원유형
- 실제 저장 방식
- 현재 회원유형에서 이용할 수 있는 기능
- Pro 전환 시 추가되는 기능

분석 횟수, 티켓, 주간 갱신, 초대 보상은 표시하지 않는다.

## 8. 초대 기능

현재 회원유형 정책에는 초대 보상을 포함하지 않는다.

분석권이 없으므로 친구 +1회, 초대자 +5회 같은 횟수 보상은 사용할 수 없다. 초대 코드 UI는 숨기고, 새로운 보상안이 승인될 때 별도 정책으로 다시 정의한다.

## 9. 운영 전제

- 실제 리워드 광고는 AdMob SDK와 광고 단위가 연결된 뒤 활성화한다.
- 실제 Pro 구매는 App Store, Google Play, RevenueCat 상품이 연결된 뒤 활성화한다.
- 외부 서비스가 연결되기 전에는 광고나 결제가 성공한 것처럼 처리하지 않는다.
- 광고 완료와 Pro 권한은 클라이언트 표시만으로 신뢰하지 않고 운영 환경에서 검증한다.
