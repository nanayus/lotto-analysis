# 회원유형별 이용 정책

## 원칙

앱의 상품 등급은 `게스트`와 `Pro` 두 가지다. 로그인 여부는 상품 등급이 아니다. 로그인해도 Pro를 구독하지 않으면 게스트 정책이 그대로 적용된다.

분석권, 티켓, 일간·주간 분석 횟수는 운영하지 않는다.

## 기능 비교

| 항목 | 게스트 | Pro |
|---|---|---|
| 분석 결과 | 리워드 광고 후 전체 공개 | 즉시 공개 |
| 같은 조합 재열람 | 광고 후 공개 | 즉시 공개 |
| 한 번에 생성할 조합 | 최대 2개 | 최대 5개 |
| 직접 선택할 생성 조건 | 최대 2개 | 무제한 |
| 균형 프리셋 | 불가 | 가능 |
| AI 조합 해설 | 불가 | 가능 |
| 같은 조건으로 다시 뽑기 | 잠금 표시 | 가능 |
| Custom 분석 기간 | 불가 | 가능 |
| 내 번호 저장 | 현재 기기 | 현재 기기, 계정 연결 시 클라우드 |
| 기기간 동기화 | 불가 | 계정 연결 시 가능 |

## 게스트 UX

- 가입이나 로그인 없이 핵심 기능을 바로 사용한다.
- 번호와 즐겨찾기는 현재 기기에 저장한다.
- 결과를 새로 열거나 다시 열 때 리워드 광고를 완료한다.
- 세 번째 조건을 선택하면 기존 조건을 비활성화하고 `Pro 살펴보기`를 제공한다.
- 조건 선택 화면에는 한 줄짜리 Pro 안내만 표시하며 사용자가 닫을 수 있다.

## Pro UX

- 결과를 광고 없이 바로 본다.
- 조건 선택 화면에 처음 진입하면 추천 조건 적용 여부를 한 번 묻는다.
- 생성 조건을 제한 없이 선택하고 균형 프리셋을 사용한다.
- AI 해설, 같은 조건으로 다시 뽑기, Custom 기간을 사용한다.
- 저장한 번호를 계정의 클라우드에 보관하고 기기간 동기화한다.

## 로그인 역할

Firebase 익명 인증은 로그인 화면 없이 서버 요청과 스토어 구매를 사용자별로 구분하는 내부 수단이다. Apple·Google 계정 연결은 Pro 구독 조건이 아니며, 클라우드 동기화와 앱 데이터 복원에만 사용한다. 로그인 화면에서 기능 한도 증가를 약속하지 않는다.

## 문구 원칙

- 한 화면에서 같은 혜택을 반복 설명하지 않는다.
- 잠금 시점에만 짧게 제한과 Pro 혜택을 설명한다.
- 분석은 과거 데이터 탐색이며 당첨 예측이나 추천이 아님을 유지한다.

## 상단 플랜 표시

- 주요 탭 헤더에는 현재 등급 하나만 `FREE` 또는 `PRO` 상태 배지로 표시한다.
- 배지는 주요 CTA와 경쟁하지 않는 낮은 강도의 캡슐으로 표시하고, `PRO`만 강조 표면과 글자색으로 구분한다.
- `FREE`를 누르면 공통 Pro 결제 안내를 연다.
- `PRO`를 누르면 Pro 이용 상태와 서버가 제공한 이용 만료일을 보여준다.
- 자동 갱신 여부처럼 서버에서 확인할 수 없는 정보는 표시하지 않는다.
